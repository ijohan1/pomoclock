# pomoclock - простий та легкий у використанні помодоро таймер, написаний на пайтоні, здатний вести обік пропрацьованого часу.


# швидке ознайомлення

Метод Pomodoro - це метод керування часом, розроблений Франческо Чірілло в кінці 1980-х. Цей метод використовує таймер для того, щоб розбити роботу на 25-хвилинні інтервали, які називаються pomodori і розділені короткими перервами.

Дана програма базується саме на цій концепції . 

## переваги:

- просте клавіатурне керування 
- живий підрахунок завершених робочих сесій
- вбудований системний звук сповіщення в кінці кожного відрахунку (без жодних додаткових файлів!)
- можливість виходу з відображенням загального відпрацьованого часу
- запис даних кожної сесії до окремого .json файла (автоматично створюється та оновлюється разом з папкою data)

# вимоги:
- python v3.14.4 або новіший (теоретично можна використовувати також старішу версію, але ця можливість ще не була з'ясована)
- будь-який термінальний емулятор
- ОС на базі Linux (опціонально, оскільки може запуститися на Windows, але найлегше запустити саме таким чином)

# інсталяція:
1. завантажте pomodoro.py файл з цього репозиторія. 
2. запустіть його у власному терміналі системним python/IDE/тощо.
для користування жодних сторонніх файлів чи завантажень здійснювати не потрібно.

# використання:
пауза/продовження - ENTER 
завершити роботу таймера - q + ENTER
