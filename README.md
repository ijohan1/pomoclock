# pomoclock - a simple and easy to use pomodoro timer in python able to track your work hours.

# quick intro

The Pomodoro Technique is a time management method developed by Francesco Cirillo in the late 1980s. It uses a kitchen timer to break work into intervals, typically 25 minutes in length, separated by short breaks. Each interval is known as a pomodoro, from the Italian word for tomato, after the tomato-shaped kitchen timer that Cirillo used while he was a university student.

This tool is based on the idea of Pomodoro Technique. 

## features:

- simple input control (ENTER key to pause & resume the timer)
- finished work session counter
- embedded system sound at the end of each session (no additional files needed)
- quit function with displaying how much time you spent working in total (q key, then press ENTER)
- writing the data of each session's total time in .json file (automatically creates data folder with the file inside)


# requirements:
- python v3.14.4 or slightly older (how low can you actually go with your python version is yet to be tested) 
- terminal emulator of your choice
- preferably linux environment (optional, because can run on Windows, but again this possibility is untested yet)

# installation:
1. download the pomodoro.py file from this repository. 
2. launch it in your terminal emulator with python.
no other files or instances is required to use the application. 

# usage:
pause/resume - ENTER 
q + ENTER - quit timer
